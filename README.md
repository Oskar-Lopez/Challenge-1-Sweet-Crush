## 📖 Descripción

Juego **Sweet Crush** implementado en **C++ de consola**, donde cada ficha se almacena en **3 bits** dentro de un buffer dinámico. Usa operadores bitwise, punteros y memoria dinámica, sin `struct`, `class`, `template`, STL ni `string`.
